# Custom Projectiles

A UCP3 module for Stronghold Crusader and Stronghold Crusader Extreme: configure projectile types,
volley sizes and automatic firing for every unit type with one readable YAML file. The module and
its full documentation are in [module/](module/README.md).

## Install

Download the zip from the latest release, then in the UCP3 GUI use **Install extension** (or drag
the zip onto the window), press **F5** and enable **Custom Projectiles**.
